First public release of BrickForge: describe a model or attach a photo, and Claude designs it in interlocking bricks that can really be built, with a 3D view, step-by-step instructions, a parts list and LDraw export. See the [README](https://github.com/HariGuns/brickforge#readme).

## Downloads

| System | File | Status |
|---|---|---|
| **Windows** | `BrickForge-0.1.0-portable.exe` | **Recommended for now.** Tested under Wine: launches, accepts an API key, completes a simulated build. No install needed. |
| Windows | `BrickForge-Setup-0.1.0.exe` (installer) | **Untested.** Use the portable .exe until it's been checked. |
| macOS (Apple silicon and Intel) | `BrickForge-0.1.0-universal.dmg` | **Untested.** |
| Linux | `BrickForge-0.1.0-x86_64.AppImage` | Tested: launches, accepts an API key, completes a simulated build. `chmod +x`, then run. |

All builds are unsigned: Windows SmartScreen and macOS Gatekeeper will warn on first launch. The README explains how to open them.

## First launch

You need your own [Anthropic API key](https://console.anthropic.com/). The app asks for it on first launch, checks it, and stores it only on your computer. No build contains a key. Every build is capped at **$5** by default (change it in the Cap menu). Typical costs: $0.12–0.56 for a Standard model, up to about $3 for a large Very high one.

## Highlights

- Large models planned as trees of sub-builds, with a reusable component library (109 components included).
- A validator that checks every part is buildable, and a repair loop that isn't allowed to fix problems by deleting planned features.
- Scenes on real baseplates; sideways panels on side studs; wheels on pins; photo builds compared with the photo.
- 983 parts from the LDraw library (part data under CC BY-SA 4.0; see NOTICE.md).
